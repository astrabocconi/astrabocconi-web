# Calculators

Four calculators live under `/calcolatori`: the graduation calculator at
`/calcolatori/bachelor`, `/calcolatori/master` and `/calcolatori/clmg`, and the
Master admissions calculator at `/calcolatori/ammissioni-magistrale`. The index
page and the homepage show one card per route (`CalculatorCards`).

## Source of truth: the astra-app monorepo

The app's calculators are the reference; the website matches them in courses,
plans, logic, features and Italian copy. Resynced 2026-10-08 from
`Desktop/astra-app` (not the older `~/astra-app`):

## Differences from the app, and why

- **No profile.** The app opens on the student's own degree type and
  programme. The website has no login, so it opens on the first programme in
  the picker (what the app does for a student without a profile);
  `defaultPlan(type)` takes no profile argument.
- **Degree type is a route**, not a toggle, so each calculator has its own URL.
- **Layout.** On desktop the exam list sits left and the average plus the two
  panels (graduation grade, target simulation) sit in a sticky column, switched
  by a segmented control instead of two accordions. The app's bottom-sheet
  grade picker is an inline editor under the exam row.
- **Admissions chance pills** use the brand palette (primary, gold, light)
  instead of the app's green and amber.
- **Saving.** One transcript per degree type in localStorage
  (`astra.web.calculator.v1.<type>`, same shape as the app's `SavedCalc`), the
  admissions inputs under `astra.web.masters.v1`. Local to the browser; no
  sync with the app. The admissions page offers the bachelor calculator's
  average, as the app does.
- **Web extras kept:** a link to the Bocconi rules for each degree type, and a
  hint to add only the best two extra exams.

The website used to round bachelor honours on the unrounded total and to
derive the target from rounded module grades. Those fixes were dropped in the
2026-10-08 resync because the app is the source of truth: if they are right,
fix them in astra-app and resync.

## Verification

`npm run test:calculators` (Node 22.18+ or 24) runs `scripts/test-grade-calc.mjs`,
which imports the three ported app suites: 24 tests covering weighted averages,
pass/fail, honours, integrated modules, internship replacement, caps, target
simulation, combination counts, admission scores and outlook, and every plan.
